## 🧩 Практична задача: декоратор `@cache_result`

Напиши власний декоратор `@cache_result`, який **запам'ятовує результати викликів функції**.

### Приклад №1

Є функція:

```python
@cache_result
def get_square(number):
    print(f"Calculating {number}...")
    return number ** 2
```

При першому виклику:

```python
print(get_square(5))
```

має виконатися функція і вивести:

```text
Calculating 5...
25
```

Якщо викликати її повторно:

```python
print(get_square(5))
```

результат має бути:

```text
25
```

При цьому:

```text
Calculating 5...
```

**вдруге виводитися не повинен**, тому що результат для `5` вже є в кеші.

---

### Приклад №2

Декоратор повинен працювати і з функціями, які мають декілька аргументів:

```python
@cache_result
def add(a, b):
    print(f"Calculating {a} + {b}...")
    return a + b
```

Для такого коду:

```python
print(add(2, 3))
print(add(2, 3))
print(add(5, 10))
print(add(2, 3))
```

очікуваний результат:

```text
Calculating 2 + 3...
5
5
Calculating 5 + 10...
15
5
```

Тобто функція реально повинна виконатися лише для:

```text
(2, 3)
(5, 10)
```

А повторний виклик:

```python
add(2, 3)
```

повинен повертати вже збережений результат.

---

### Обмеження

Не використовуй:

```python
functools.lru_cache
```

Механізм кешування потрібно реалізувати самостійно.

Декоратор повинен:

1. Приймати будь-яку кількість позиційних аргументів через `*args`.
2. Приймати keyword arguments через `**kwargs`.
3. Зберігати результати в словнику.
4. При повторному виклику з такими самими аргументами повертати результат із кешу.
5. Не викликати оригінальну функцію повторно.
6. Використовувати `functools.wraps`.
7. Продемонструвати працездатність реалізації одним із двох способів:

   * виконати **10 викликів** із випадковим вибором одного з **3–5 заздалегідь підготовлених наборів аргументів**;
   * реалізувати **нескінченний цикл**, у якому користувач може вибрати функцію для виклику та ввести значення її аргументів.

### Підказка

Тобі знадобляться:

```python
from functools import wraps
```

і:

```python
*args
**kwargs
```

Основна ідея:

```text
                 ┌── результат є?
виклик функції ──┤
                 │
                 ├── ТАК → повернути результат з cache
                 │
                 └── НІ → викликати функцію
                            ↓
                         зберегти результат
                            ↓
                         повернути результат
```
